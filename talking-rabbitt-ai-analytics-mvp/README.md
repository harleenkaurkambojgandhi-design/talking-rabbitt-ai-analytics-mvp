# Talking Rabbitt – Conversational AI Analytics MVP

## Overview

Talking Rabbitt is a conversational intelligence layer that enables leaders to interact with business data using natural language queries.

Instead of navigating dashboards, users can simply **ask questions about their data and receive instant insights with visualizations.**

This project demonstrates the **MVP prototype** of Talking Rabbitt.

---

## Problem

Traditional analytics tools like:

* Microsoft Power BI
* Tableau

require users to navigate dashboards and apply filters manually.

This process is time-consuming and requires technical knowledge.

---

## Solution

Talking Rabbitt introduces a **conversational query layer** that allows users to ask natural language questions and instantly receive insights.

Example:

User Question:

"Which region had the highest revenue?"

System Output:

• Text insight
• Automated bar chart

---

## Features

• Upload CSV dataset
• Natural language query interface
• Automated data analysis
• Dynamic visualization

---
